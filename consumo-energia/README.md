📌 Sobre o projeto

A Calculadora de Consumo Elétrico é um programa desenvolvido em Python que permite estimar o consumo mensal de energia de um aparelho a partir de sua potência e do tempo médio de uso diário. ⚡

Fórmula utilizada
O cálculo é realizado utilizando a seguinte fórmula:
Consumo mensal = (potência × horas de uso por dia × 30) ÷ 1000

▶️Como executar
Abra a pasta do projeto no VS Code e execute o arquivo app.py pelo terminal com o comando:
python app.py
Depois, informe o nome do aparelho, a potência em watts e o tempo médio de uso diário. O programa mostrará o consumo estimado em kWh/mês.
