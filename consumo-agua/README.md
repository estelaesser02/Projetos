💧 Consumo de Água

📌 Sobre o projeto

O Consumo de Água é um sistema desenvolvido em Python para classificar o perfil de consumo de água de imóveis e emitir alertas educativos aos moradores.
O programa considera o tipo de imóvel e o consumo mensal para apresentar uma mensagem de orientação.

🎯 Objetivo

Promover a conscientização sobre o consumo de água, identificando consumos econômicos, moderados ou excessivos.

💻 Tecnologias
🐍 Python
🐙 GitHub

▶️ Como executar
Abra a pasta do projeto no VS Code.
Abra o terminal.
Entre na pasta consumo-agua.

▶Execute:
python app.py
Informe o tipo de imóvel e o consumo mensal quando solicitado.
