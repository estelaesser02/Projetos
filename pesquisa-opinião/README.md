# Pesquisa de Satisfação - TudoWeb

​🌐​ Sobre o projeto

Programa desenvolvido em Python para realizar uma pesquisa de satisfação com clientes da empresa TudoWeb.

O sistema coleta:
- Nome
- Idade
- Opinião sobre o atendimento

As opções de avaliação são:
1. Excelente
2. Bom
3. Ruim

Ao final, o programa apresenta a quantidade de respostas Excelente e Ruim.

▶️​ Como executar

Execute o arquivo `app.py` pelo Python
