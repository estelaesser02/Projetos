Sistema de Desconto Progressivo
Sobre o projeto 📍​

Este projeto é um programa em Python que calcula o desconto de uma compra de acordo com o seu valor total.

Regras de desconto ​​🧾​
Compras abaixo de R$ 200,00 → 5% de desconto
Compras de R$ 200,00 até abaixo de R$ 300,00 → 10% de desconto
Compras a partir de R$ 300,00 → 15% de desconto

Como executar ​⬇️​
Tenha o Python instalado no computador.
Abra a pasta do projeto no VS Code.
Execute o arquivo app.py.
Digite o valor total da compra quando solicitado.

Tecnologias utilizadas 🖥️​
Python 🐍
Visual Studio Code
